\# Project Architecture



\## Overview



This project is organized as a modular machine learning pipeline for predicting systolic blood pressure from sleep health and lifestyle data.



\## Workflow



1\. Load data

2\. Validate schema and data quality

3\. Engineer features

4\. Run exploratory analysis

5\. Build preprocessing pipelines

6\. Train candidate models

7\. Run cross-validation

8\. Tune hyperparameters

9\. Evaluate final models

10\. Save outputs and reports
