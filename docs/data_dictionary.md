\# Data Dictionary



\## Person ID

Unique identifier for each record.



\## Gender

Reported gender category.



\## Age

Age of the individual.



Expected range: 18–100.



\## Occupation

Occupation category.



\## Sleep Duration

Average sleep duration in hours.



Expected range: 0–24.



\## Quality of Sleep

Sleep quality score.



Expected range: 1–10.



\## Physical Activity Level

Physical activity score or activity level measure.



Expected range: 0–100.



\## Stress Level

Stress score.



Expected range: 1–10.



\## BMI Category

Body mass index category.



\## Blood Pressure

Blood pressure value in systolic/diastolic format.



Example: 120/80.



\## Heart Rate

Heart rate in beats per minute.



Expected range: 30–220.



\## Daily Steps

Number of daily steps.



Expected range: 0–100000.



\## Sleep Disorder

Sleep disorder classification.



Missing values are treated as No Disorder.
