\# Monitoring Plan



\## Purpose



This project includes lightweight monitoring utilities to evaluate whether future input data differs from the training data.



\## Schema Monitoring



The pipeline can compare reference and current datasets to detect:



\- missing columns

\- new columns



\## Numeric Drift Monitoring



Numeric features can be compared using mean percentage change.



Examples:



\- Age

\- Sleep Duration

\- Stress Level

\- Heart Rate

\- Daily Steps



\## Prediction Monitoring



Prediction outputs can be summarized using:



\- count

\- mean

\- minimum

\- maximum

\- standard deviation
